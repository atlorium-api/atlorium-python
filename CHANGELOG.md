# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-03

Первый релиз.

### Добавлено

- Синхронный `Atlorium` и асинхронный `AsyncAtlorium` клиенты.
- Все 23 сервиса Atlorium, 59 методов: ЕГРЮЛ/ЕГРИП, БИК, SWIFT, BIN, AML, профиль IP, ГАР/ФИАС,
  стандартизация адреса, телефон, e-mail, OCR, DNS, CIDR, cron, SSL, погода, ИИ-чат, прямой и обратный
  геокодинг, тестовые данные, проверка ссылок, аудит сайта, модерация изображений.
- Типы параметров и ответов (`atlorium.types.<сервис>`), сгенерированные из OpenAPI-спек.
- Иерархия исключений по HTTP-статусам, ретраи на 429/503 и сетевых ошибках с учётом `Retry-After`.
- `PermissionDeniedError` для ответа 403: сервис не входит в условия учётной записи
  (код `service_not_in_account_terms`). Не повторяется.
- `ServiceUnavailableError` (503) — подкласс `ServerError`: `except ServerError` ловит любой ответ 5xx.
- 503 с кодом `service_disabled` или `maintenance` (плановые работы) не повторяется — исключение сразу.
  Прочие 503 повторяются как обычно.
- `retry_after` есть у всех исключений (`AtloriumError`), а не только у `RateLimitError`: значение
  `Retry-After` в секундах или `None`. Если сервер просит ждать дольше двух минут, сразу бросается
  исключение соответствующего статуса (`RateLimitError` для 429, `ServiceUnavailableError` для 503).
- Метаданные ответа через `with_raw_response`.
- Демо-режим без ключа на публичном sandbox-ключе; если ключ не задан вовсе — `AtloriumSandboxWarning`.
- POST после сетевой ошибки повторяется, только если соединение не установилось: повтор после таймаута
  мог бы выполнить платную операцию второй раз.
- Строка, похожая на путь к несуществующему файлу или на ссылку, в `ocr`/`imagecheck` — понятная ошибка
  вместо отправки на сервер.
- Таймаут `aichat.send` по умолчанию — 660 с (11 минут): развёрнутый ответ модели может готовиться
  несколько минут, а обрыв соединения клиентом не отменяет оплату запроса.
- `testdata.generate` и `testdata.generate_with_body` одинаково принимают `fields` строкой или списком строк.
- Зависимость — `httpx>=0.26,<1`.
